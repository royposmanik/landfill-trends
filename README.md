# Landfill Trends: the world and Israel

Interactive, bilingual (English / Hebrew) dashboard of municipal solid waste landfilling worldwide and in Israel.
Prepared for the Technion course **Solid Waste Management (0160338), 2026-7**.

Live site: https://landfill-trends.vercel.app

## What it shows

**Part 1: the world**
- World map of landfilling for the 38 OECD member countries, year by year (2000–2024), or the World Bank *What a Waste 2.0* snapshot for every country.
- Where municipal waste goes, by world region.
- Landfilled kg per person against GDP per person, year by year, for OECD members and for about 120 countries worldwide.

**Part 2: Israel**
- Israel at a glance, Israel against the OECD over time, Israel's waste treatment mix and its rank among OECD countries.
- Map of Israel's landfills sized by the methane each reported to the Pollutant Release and Transfer Register, 2012–2025.
- Remaining landfill space at each site and planned expansions.

Every animated chart can be downloaded as a GIF.

## Data sources

| File | Source |
|---|---|
| `data/oecd_landfill_trends.csv` | OECD, Municipal waste: generation and treatment (DF_MUNW); World Bank GDP per capita (PPP) via Our World in Data |
| `data/world_landfill_trends.csv` | OECD (above) plus UN Statistics Division environment statistics, waste questionnaire country files; population and GDP via Our World in Data |
| `data/waw_country_landfill.csv` | World Bank, *What a Waste 2.0* country-level data |
| `data/il_landfill_methane.csv` | Israel Ministry of Environmental Protection, Pollutant Release and Transfer Register (data.gov.il) |
| `data/il_landfill_capacity.csv` | State Comptroller of Israel, follow-up audit on municipal waste disposal (July 2025, table 3); Knesset Research and Information Center (January 2026, table 1) |
| `data/world.js`, `data/il.js` | Country outlines (Natural Earth, public domain) |

Figures are as reported by each source; see the "Definitions and caveats" section on the page for how they were combined and their limits.

## How it is built

- `index.html` is generated by `node scripts/build_site.js` from `dashboard_page.html`, the page source of the original dashboard.
- `site/runtime.js` provides the small data-loading and drawing runtime the page expects; charts use [D3](https://d3js.org).
- `scripts/` holds the scripts that built the data files (`build.js`, `un_build.js`, `il_build.js`) and the Hebrew translations (`he_static.js`, `he_exact.js`).
- GIF export uses [gifenc](https://github.com/mattdesl/gifenc) (MIT).

It is a static site: open `index.html` through any web server, or deploy the folder as is.
